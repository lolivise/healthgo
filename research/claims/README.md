# Claims checked (/ask myth-buster)

Every health claim Darren sends through Telegram `/ask` (a YouTube video, a web page, or something he heard) is
traced back to its source paper, graded, and checked against his own situation. Each check is filed here so the
next time the claim (or the same YouTuber) comes up, the answer is already known.

- **One file per source**: `YYYY-MM-DD-<slug>.md`, 繁中, the exact text sent to Telegram. A video with several
  claims is one file with one block per claim.
- **Search here first.** Before researching a new `/ask`, grep this folder and the index below. A claim checked
  within ~2 years is answered from its file (plus anything new); older ones get re-pulled.
- **`sources.md`**: track record per channel / site / person: how many of their claims held up.
- When a check produces real evidence on a topic his plan depends on, the matching `.claude/memory/evidence-*.md`
  file gets the row too (current best answer, ≤ ~50 lines, per `/knowledge-review`'s lean rule). This folder keeps
  the claim-level record (who said it, what they got wrong); evidence files keep the science.

Verdicts: ✅ 成立 · 🟡 部分成立／誇大 · ❌ 誤導／錯誤 · ❓ 證據不足
