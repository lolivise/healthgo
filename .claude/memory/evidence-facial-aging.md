Darren worries (2026-10-25) that losing weight fast will age his face / destroy facial collagen, which is hard to
repair at 36. Full 繁中 report: `research/medical/慢性發炎 減重過快 臉部老化.md`. **[V]** found online, **[U]** unverified.

| Claim | Verdict | Evidence |
|---|---|---|
| Fast fat loss destroys facial collagen | **Myth / never measured** | Only biopsy comparison: same collagen after surgical vs non-surgical massive loss (49.2 vs 49.5 %; elastin higher the longer since loss; Hany 2024 [V]). GLP-1 skin mechanisms are cell/animal only (Paschou 2025) |
| "Ozempic face" is drug toxicity | **Unproven** | 2025 systematic review, 23 papers, 3 with controls, no imaging: "evidence … lacking" (Daneshgaran 2025 [V]); it is deflation after any large loss (Sciscent 2025) |
| Big loss makes faces look older | **Partly**: massive (bariatric) loss looked +5.1 y vs +1.2 y; worse **over 40** (Jafar 2024 [V]) | |
| Rate of loss decides it | **Never studied** (Jafar 2024 says so explicitly) | |
| Under 40, losing weight looks younger | Direction only: twins, higher BMI looked older before 40, younger after (Guyuron 2009, landmark) | |
| Oral collagen works | **No**: independent / high-quality trials null (Myung & Park 2025 [U primary]); also breaks his supplement rule | |
| Daily sunscreen slows skin aging | **RCT**: Nambour, daily vs discretionary, 4.5 y, "24 % less" [U figure] | |
| Tretinoin improves photoaging | **Meta-analysis**, 8 RCTs, 1,361 pts; prescription in AU; dries skin | |
| Lifting thickens dermis | Preliminary: Nishikori 2023, small, Japanese women | |
| Poor sleep / sugar age skin | Weak (Estée Lauder-funded) / mechanism only | |

**Applied to him:** 102 → 80–83 kg = 19–22 % of start weight (GLP-1 range, far below bariatric 40–50 %), age 36 (under
40). BMI 32.6 → 28.1; observers notice ~1.3 BMI units in a male face, so a visibly changed face is expected, not damage.
Volume (fat pads) and wrinkles/pigment (UV) are separate problems. In Chinese skin photoaging shows mainly as
**pigmentation** (1,081-person cohort 2024 [V]); sagging tracks age, not sun (Flament 2013).
If rate matters at all, the plausible reason is skin lagging behind a fast deflation: a minor extra reason to slow near
the goal, not an evidence-backed one.

**Prevention, ranked:** (1) **SPF50+ every day UV ≥3** (Cancer Council: apply 20 min before, reapply every 2 h outdoors,
plus hat/shade; Perth is ≥3 most of the year) — he currently uses it "most mornings", so not daily;
(2) topical retinoid, via GP/dermatologist, **only after the current dryness settles** ([[skin-dryness-itch]]);
(3) keep lifting; (4) sleep; (5) don't smoke (he doesn't). Facial volume only returns with regained fat or fillers:
literature says wait **≥6 months of stable weight** before any facial procedure.
