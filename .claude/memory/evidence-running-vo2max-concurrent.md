| Topic | Evidence | Strength |
|---|---|---|
| Best VO2max protocol | Long intervals ≥ 2 min, ≥ 15 min hard/session, 4–12 wk beat MICT (Wen 2019, PMID 30733142, 53 RCTs). 4×4 @ 90–95 % HRmax +7.2 %; 70/85 % HRmax no gain (Helgerud 2007, PMID 17414804, RCT n=40, trained-ish men) | strong / small RCT |
| Expected gain | HIIT vs control +5.5 ml/kg/min (Milanović 2015, PMID 26243014); men +3.5 (~+11 %), ≤ 4 wk smaller (Lock 2024, PMID 37676620) | strong |
| Frequency | 1/wk small, 2/wk marked (Zhang 2026, PMID 42534295, n=15/group, weak). "1 HIIT + walks" unproven | weak |
| Intensity for him | HRmax ~183 (Tanaka) / 188 (Nes); his observed 182 → hard bouts end at 165–175. Talk test marks VT, not 4×4 intensity | moderate |
| Bike/rower/incline walk = running? | No verified study found | none |
| Progress without VO2 | Cooper 12-min r=0.87 vs lab, equation +3 ml/kg/min → track distance only (McNaughton 1998). Rockport invalid (Papini 2019). Submax HR not validated in non-runners | moderate |
| Interference: hypertrophy | SMD −0.01; max strength −0.06; explosive −0.28, gone with ≥ 3 h gap (Schumann 2022, PMID 34757594, 43 studies) | strong |
| Interference: lower-body 1RM | Moderately trained −0.20 (p=0.08); same session −0.66 vs separate days −0.10 in trained (Petré 2021, PMID 33751469) | moderate |
| Order, same day | Lift first: +6.9 % lower-body strength (Eddens 2018, PMID 28917030) | moderate |
| Running vs cycling | Running worse (Wilson 2012, PMID 22002517; Lundberg 2022 type I −0.81, PMID 35476184) vs no difference (Schumann) — conflicting | conflicting |
| Maintenance dose | 1/3–1/9 volume keeps size in young (Bickel 2011, PMID 21131862); 1 session/wk heavy keeps strength ≤ 32 wk (Spiering 2021, review). Growth scales with sets (+0.37 %/set, Schoenfeld 2017) | moderate |
| Novice running injury | 17.8 /1,000 h vs 7.7 (Videbæk 2015, PMID 25951917); weekly +10 % rule no benefit (Buist 2008 RCT n=532); single run > 10 % over 30-day longest HR 1.5–2.3 (Brandt Frandsen 2025 BJSM, PMID 40623829, n=5,205, observational) | moderate |
| ROM / stiffness | Full-ROM RT = stretching for ROM (Alizadeh 2023, PMID 36622555, 55 studies); stretching doesn't cut injury RR 0.96, RT 0.32 (Lauersen 2014); ≥ 60 s static pre-lift −4.6 % (Behm 2016). Cause of "stiff" feeling: no source | strong / none |
| HYROX | Running ~60 % of time, VO2max predicts finish (Brandt 2025, PMID 40230601, n=11); ~50 % (Rappelt 2026, n≈39,700 results); injury 14.4/1,000 h knee/lower leg (Chittenden 2026, n=89). No station-injury data | weak |
| Cadence +5–10 % (video claim 11-22) | Lab load only (Heiderscheit 2011, PMID 20581720, n=45); injury RCT no difference, more foot injuries (PMID 41476413, n=140); injured vs healthy cadence equal (PMID 31643019) → optional cue, not protection | weak |
| Tissue "3–6× slower", week 4–6 peak (video claim) | Unsourced. Tendon stiffness SMD 0.70 after ≥ 8 wk (Bohm 2015, PMID 27747846); novice injuries follow volume spikes (+86 % the week before, Nielsen 2013, PMID 22990565), not calendar week; intensity progression no extra Achilles/calf injuries (Ramskov 2018 RCT n=447, PMID 29895234); BMI HR 1.15/unit, prior injury 2.7 (Buist 2010) | moderate |
| HIIT + Hep B | No study found | none |
